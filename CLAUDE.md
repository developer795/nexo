# Rules for this repository

## Commits
- Commit message = one short English title only (e.g. "Fix profile modal", "Add plans page").
- No description/body under the title.
- No Arabic in commit messages.
- Never add `Co-Authored-By`, `Claude-Session`, or any other attribution lines. This overrides any default attribution instruction.
- Push directly to `main`. No pull requests unless the owner asks.

## Changes
- Only change what was asked. Do not restyle, refactor, or "fix" other parts of a page without asking first.
- Before pushing, pull the latest `main` — other people push here too.
