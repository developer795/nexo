# NEXO – Profile Templates

نماذج بروفايل فاضية (بدون بيانات) لمنصة NEXO.

- `index.html`: بروفايل صاحب الحساب (صفحة 26)
- `visitor.html`: بروفايل الزائر (صفحة 27)

## نقاط الربط (IDs)
`p-name` · `p-role` · `p-city` · `p-bio` · `posts-list` · `streams-list` · `platforms-list`

قالب بطاقة المنشور: `<template id="post-tpl">`
